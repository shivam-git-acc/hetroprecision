This is the before and after cost. The naive path stores int4 but converts the whole cache back to BF16 before every attention call, so it saves memory and costs up to 2.6 times the time; int2 is no faster than int4. The fused path reads FP8 inside the attention kernel: twice the capacity and up to 22 percent faster. Our per-head mixed-precision kernel must be of the fused kind.
