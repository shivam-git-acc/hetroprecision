Batch 1 is weight-bound

The kernel library matters too

BF16 at 32K × 8: FlashAttention 41.1 ms, FlashInfer 26.1 ms (bound 24.6). FlashAttention’s attention kernel is only ~9 ms of it; the rest is still open.
